# Wheek

A guinea pig vocalisation classifier and behaviour logger.

Listens to a cage, classifies calls into the standard ethogram (wheek, chut,
rumble, chatter, purr), attempts to identify which individual pig called, and
logs everything with timestamps so you can answer real questions: is wheeking
contagious? Do they call more when separated?

It is a classifier, not a translator. Meanings come from published ethology; the
software's job is reliable, timestamped, honestly-scored evidence.

See [CLAUDE.md](CLAUDE.md) for goals, architecture, evidence standards and how work is
delivered, and [CONTRIBUTING.md](CONTRIBUTING.md) if you want to propose a change.
